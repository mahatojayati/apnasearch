🔎 ApnaSearch

Your personal media. Your search engine.

ApnaSearch is a lightweight, browser-based media search engine that helps you organize and find your photos and videos using keyword-based search.

✨ Features
📸 Upload multiple images and videos.
🔍 Search by filename and description.
🎯 Relevance-based search results.
🏷️ Filter photos and videos.
💾 Store media locally using IndexedDB.
🎬 Preview images and videos.
🗑️ Delete uploaded media.
🛠️ Tech Stack
HTML5
CSS3
JavaScript
IndexedDB
🚀 Getting Started

Clone the repository:

bash
git clone https://github.com/mahatojayati/apnasearch.git


Open the project folder and simply launch index.html in your browser.

No installation or additional setup required.

🔐 Privacy

Media is stored locally in your browser using IndexedDB. No project backend or cloud storage is required.

Note: Clearing browser site data may permanently delete your stored media.
